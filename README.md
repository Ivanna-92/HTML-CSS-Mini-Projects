# HTML & CSS Mini Projects

A collection of small HTML and CSS projects created while practising web development.

These projects cover different areas of HTML, CSS, forms, iframes, page layouts, and Tailwind CSS.

## Projects

- **Contact Form** — A simple contact form using HTML form elements and CSS styling.
- **Iframe** — A practice project using an iframe and CSS styling.
- **Tailwind Project** — A small project using Tailwind CSS for styling.
- **Chanted Website** — A small website project built with HTML and CSS.
- **Second Web** — Another small website created for HTML and CSS practice.

## What I Practised

- HTML structure
- Headings, paragraphs and links
- Forms and form elements
- Iframes
- CSS styling
- Page layouts
- Working with images
- Tailwind CSS
- Basic responsive design

## Tools

- HTML
- CSS
- Tailwind CSS

## Purpose

These projects were created as small practical exercises while learning web development. 
Each project focuses on different HTML and CSS features and helped me practise building web pages from scratch.
